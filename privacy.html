이 앱은 서버를 두지 않습니다. 사진, 메모, 태그는 여러분의 기기 안이나 여러분이 직접 연결한 저장 공간에만 저장되고, 운영자를 포함한 누구에게도 전송되지 않습니다.

수집하는 정보

없습니다. 이 앱에는 계정 데이터베이스도, 분석 도구도, 광고도, 추적 스크립트도, 쿠키를 심는 코드도 없습니다. 여러분이 무엇을 담았는지 운영자는 알 수 없습니다.

기록이 저장되는 곳

  • 브라우저 안 — 기본값입니다. 기기의 IndexedDB(gusuk-archive)에 저장되며 해당 브라우저 밖으로 나가지 않습니다.
  • 직접 고른 폴더 — 컴퓨터에서 폴더를 연결하면 그 폴더에 파일로 저장됩니다. 폴더 선택과 접근 허가는 매번 여러분이 직접 합니다.
  • 구글 드라이브 — 드라이브 로그인을 사용하는 경우, 기록은 여러분 본인의 구글 드라이브에 저장됩니다. 운영자의 저장 공간이 아닙니다.

구글 계정으로 로그인할 때

드라이브 연동은 drive.file 권한만 요청합니다. 이 권한은 이 앱이 직접 만든 파일에만 접근할 수 있습니다. 드라이브에 이미 들어 있는 다른 문서·사진·폴더는 이 앱이 열람할 수 없으며, 존재 여부조차 알 수 없습니다.

인증 토큰은 여러분의 브라우저에만 보관되며 외부로 전송되지 않습니다. 로그아웃하거나 구글 계정 권한 설정에서 언제든 접근을 취소할 수 있습니다. 취소해도 드라이브에 저장된 파일은 그대로 남습니다.

외부로 나가는 요청

앱이 접속하는 외부 주소는 다음뿐입니다.

  • Google Fonts — 글꼴 파일을 받아옵니다. 최초 1회 이후에는 기기에 저장돼 오프라인에서도 동작합니다.
  • Google Drive API — 드라이브 로그인을 사용할 때만, 여러분의 파일을 여러분의 드라이브에 읽고 쓰기 위해서만 사용합니다.

그 외 어떤 서버로도 통신하지 않습니다.

기록을 지우는 방법

  • 앱 안에서 사진을 개별 삭제
  • 브라우저의 사이트 데이터 삭제 (해당 기기의 기록이 전부 지워집니다)
  • 연결한 폴더나 드라이브 폴더를 직접 삭제

운영자가 보관하는 사본이 없으므로, 여러분이 지우면 그것으로 끝입니다. 같은 이유로 운영자는 복구를 도와드릴 수 없습니다. 앱의 백업 저장 기능을 주기적으로 사용해 주세요.

아동의 개인정보
