# 좋아하는 구석 — MCP 서버

Claude 가 아카이브를 직접 읽고 쓸 수 있게 열어준다.
"올리브가 붙은 사진들 모아서 공통점 찾아줘", "이 사진들 옵시디언으로 내보내줘" 같은 게 된다.

의존성 없음. `npm install` 필요 없음. Node 18+ 만 있으면 된다.

---

## ⚠️ 먼저 — 폴더 모드여야 한다

MCP 서버는 **파일을 읽는 프로그램**이다. 그래서 아카이브가 파일로 있어야 한다.

| 저장 방식 | MCP 접근 |
|---|---|
| **연결한 폴더** (앱에서 "폴더 고르기") | ✅ 된다 |
| 브라우저 안 (폰, 폴더 연결 안 한 컴퓨터) | ❌ **안 된다** |

브라우저 저장소(IndexedDB)는 브라우저 샌드박스 안에 갇혀 있어서 외부 프로그램이
읽을 방법이 없다. 폰의 기록을 Claude 에게 보여주려면 `백업 저장` → 컴퓨터에서
폴더 모드로 `불러오기` 를 한 번 거쳐야 한다.

컴퓨터(Chrome·Edge)에서 앱을 열고 **"폴더 고르기"** 로 폴더를 연결하면
그 폴더가 이렇게 채워진다. 이게 MCP 가 보는 대상이다.

```
좋아하는 구석/
├ notes/      사진마다 메모·태그 한 파일 (<id>.json)
├ images/      사진 원본
├ tags.json    태그 목록
├ spaces.json  공간 이름·메모·사실
└ boards.json  무드보드와 담긴 핀
```

## 붙이는 법

### Claude Code

```bash
claude mcp add gusuk -- node "G:\내 드라이브\Claude_이세라\Claude\gusuk-app\mcp\server.mjs" "<볼트폴더경로>"
```

### Claude Desktop

`%APPDATA%\Claude\claude_desktop_config.json` 을 열고 (없으면 만들고):

```json
{
  "mcpServers": {
    "gusuk": {
      "command": "node",
      "args": [
        "G:\\내 드라이브\\Claude_이세라\\Claude\\gusuk-app\\mcp\\server.mjs",
        "<볼트폴더경로>"
      ]
    }
  }
}
```

JSON 안에서는 역슬래시를 `\\` 로 두 번 써야 한다. 저장하고 Claude Desktop 을 껐다 켠다.

경로 대신 환경변수 `GUSUK_VAULT` 로 줘도 된다.

## 할 수 있는 것

**읽기**

| 도구 | 하는 일 |
|---|---|
| `list_corners` | 담긴 사진 목록. 태그·검색어로 좁히기 |
| `get_corner` | 한 장의 전체 내용 (부분 메모와 그 위치까지) |
| `search` | 제목·인상·태그·부분 메모를 통째로 뒤지기 |
| `list_tags` | 태그 전부를 카테고리·사용 횟수와 함께 |
| `list_spaces` | 공간 목록 — 이름·메모와 객관 정보인 '사실' |
| `stats` | 몇 장인지, 자주 쓰는 태그, 자주 같이 붙는 태그 짝 |

**쓰기**

| 도구 | 하는 일 |
|---|---|
| `add_tags` / `remove_tags` | 태그 붙이고 떼기 |
| `set_note` | 한 줄 인상 쓰기 |
| `set_title` | 제목 바꾸기 |
| `set_memo` | 표시해둔 부분에 메모 쓰기 |
| `set_space` | 사진을 공간에 넣거나 빼기 (없는 이름이면 새로 생김) |

**내보내기**

| 도구 | 하는 일 |
|---|---|
| `export_markdown` | 마크다운으로 내보내기 (옵시디언용) |

## 옵시디언과 쓰기

옵시디언은 MCP 로 붙는 게 아니라 **마크다운 파일을 읽는다.** 그래서 다리는 `export_markdown` 이다.
옵시디언 볼트 안의 폴더를 `out_dir` 로 주면 그 안에 바로 노트가 생긴다.

> "좋아하는 구석 아카이브를 D:\Obsidian\내볼트\좋아하는 구석 으로 내보내줘"

나오는 형태:

```markdown
---
title: "복도 끝 창"
date: 2025-08-21
tags: ["올리브", "간접조명"]
gusuk_id: p1
---

# 복도 끝 창

![[images/p1.webp]]

오후 네시쯤 빛이 벽을 타고 내려온다

## 좋아하는 부분

**1.** 몰딩이 만나는 모서리
   #디테일

#올리브 #간접조명
```

프론트매터 태그와 본문 해시태그가 둘 다 들어가서 옵시디언의 태그 창과 그래프 뷰에
그대로 잡힌다. 사진은 `images/` 로 복사되고 `![[...]]` 임베드로 걸린다
(`copy_images: false` 로 끄면 원본 경로를 가리킨다).

`gusuk_id` 가 남아 있어서 나중에 어느 사진에서 온 노트인지 되짚을 수 있다.

⚠️ **한 방향이다.** 옵시디언에서 고친 내용은 앱으로 돌아오지 않는다.
내보내기는 덮어쓰기이므로, 옵시디언에서 단 내용은 다음 내보내기 때 날아간다.
옵시디언 쪽은 읽는 용도로 쓰고, 고치는 건 앱이나 Claude 로 하는 게 안전하다.

## 앱과 동시에 켜놔도 되나

된다. 앱은 20초마다 폴더를 다시 읽으므로 MCP 로 바꾼 내용이 알아서 반영된다.

서버는 앱과 부딪히지 않게 이렇게 짜여 있다.

1. **노트를 쓸 때 `updatedAt` 을 반드시 올린다.** 앱은 자기 것보다 새로운 노트만
   받아들이므로, 이걸 빠뜨리면 수정이 조용히 무시된다.
2. **읽고-고치고-쓰기.** 모르는 필드도 그대로 보존한다.
3. **노트 파일을 지우지 않는다.** 앱이 그걸 "사진 삭제"로 해석하기 때문이다.
4. 앱에서 **열어놓고 편집 중인 사진**은 앱이 덮어쓰기를 건너뛴다. 그쪽에서 막아준다.

그래도 같은 사진을 앱과 Claude 에서 동시에 고치는 건 피하는 게 좋다.

## 잘 안 될 때

**도구가 "notes/ 가 없습니다" 라고 한다**
→ 볼트 경로가 틀렸다. 앱에서 연결한 그 폴더(안에 `notes`, `images`, `tags.json` 이 있는)를 가리켜야 한다.

**바꿨는데 앱에 안 보인다**
→ 최대 20초 기다린다. 그래도 안 되면 앱 상단 폴더 버튼 → `지금 새로고침`.

**Claude 가 서버를 못 찾는다**
→ `node --version` 이 되는지, 설정에 적은 경로에 파일이 실제로 있는지 확인.
서버는 시작할 때 stderr 로 볼트 경로를 찍으므로 Claude 의 MCP 로그에서 볼 수 있다.
